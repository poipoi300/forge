Our nightly pipeline is actually a few steps chained together, not one job: transcode the video, generate a thumbnail from it, upload both to storage, then send a notification that it's ready. Right now I've been faking this by enqueueing each step separately and having each one kick off the next when it finishes, which works but is fragile and annoying to reason about. Also, thumbnail generation and the upload don't really depend on each other, just both depend on the transcode being done, so ideally they could run at the same time instead of one after another.

What I'd like is to submit the whole pipeline as one thing and have it show up as a single unit I can check on, but still be able to see the status of each individual step within it. If one step fails, I want it to retry just that step without redoing the steps that already finished. And if I need to bail on the whole pipeline partway through, there should be a clean way to cancel it rather than having steps keep running in the background.

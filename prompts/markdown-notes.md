# Markdown notes app

I want a small web app for writing and browsing markdown notes, mostly for myself. Vite + TypeScript, keep it simple, no backend needed — everything can just live in the browser (localStorage or IndexedDB, whatever you think fits better).

Core thing is a note editor with a live preview side by side, so I type markdown on the left and see it rendered on the right. Notes should have a title and I want to be able to tag them, like "recipes" or "work". A sidebar or list view showing all my notes would be good, and I want to search by title or by tag to quickly find things.

Doesn't need accounts or sync, this is just for my own use on one machine. Keep the UI clean and minimal, I don't need anything fancy — just something fast to jot notes into and find them again later. Feel free to pick reasonable defaults for the markdown renderer and styling.

# Follow-up: non-daily habits

Not all my habits are daily. Gym is Monday/Wednesday/Friday, and calling my mom is just once a week. Right now if I skip a day that isn't one of those days, it looks like I broke my streak, which isn't fair since I was never supposed to do it that day anyway.

Can we add the idea of a schedule per habit, so something like gym only expects action on its specific days, and a weekly one like calling mom just expects it once within the week? Streaks should only care about the days that actually matter for that habit.

Also I'd like to be able to change a habit's schedule later without losing the history I've already built up for it. Like if I decide gym should be four days a week instead of three, I don't want to lose my existing streak or past check-ins over that change.

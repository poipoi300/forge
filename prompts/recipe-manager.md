# Recipe manager

I want to build a recipe manager for myself, I'm tired of having 40 browser bookmarks and half-remembered recipes in random notes apps. I cook a lot so I want something that actually holds up to daily use, not a toy.

Core thing: I need to store recipes with a title, the ingredients (with quantities), the steps, and optionally a photo or two. I want to browse my whole collection and do a real full-text search over titles/ingredients/steps, not just a substring match on the title. I'd also like to tag recipes by cuisine (Italian, Thai, whatever) so I can filter by that.

TypeScript on both the frontend and backend. Pick whatever storage makes sense to you, I don't have a strong opinion there, just don't want something that's a pain to run locally. Keep the UI simple for now, I mostly care about getting my data in and being able to find it again fast. I'll probably ask for more stuff once this part works.
